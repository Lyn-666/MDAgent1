# MDAgent1

一个 MD agent：用户给出蛋白 PDB 和关心的区域，agent 自动搭体系、跑 MD，再找出这个区域里没有采样好的侧链。之后的版本会对这些侧链自动做增强采样。

## 现在能做什么（第 1–3 步）

1. **读入目标区域。** 可以直接给出残基（如 `A:99-120`），或者给出"某个配体周围 N Å 内的残基"。
2. **搭体系。** 用 PDBFixer 去掉配体和晶体水，补缺失原子，按 pH 加氢，再加水盒子和 0.15 M NaCl。力场为 Amber14 + TIP3P。
3. **跑 MD。** 跑几条独立的轨迹，它们只有随机种子不同。每条轨迹依次做能量最小化、NPT 平衡和 NPT 生产模拟，只保存蛋白原子。
4. **诊断侧链。** 统计每个目标残基的 chi1 二面角在 g+、t、g- 三个状态之间翻转了几次。每个残基会得到以下结论之一：

| 结论 | 含义 |
|---|---|
| `replicas_disagree` | 不同轨迹停在不同状态，结果取决于看哪一条，说明没有收敛。 |
| `no_flip` | 所有轨迹都没有翻转。侧链可能被卡住了，也可能本来就只有一个稳定状态，常规 MD 分辨不了这两种情况。 |
| `rare_flips` | 翻转过，但次数太少，还不能估计各状态的比例。 |
| `ok` | 每条轨迹都翻转了足够多次。 |
| `no_chi1` | Gly 或 Ala，没有 chi1。 |

前三种结论对应的残基，就是增强采样的候选。

## 用法

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[test]"

# T4 溶菌酶 L99A：苯周围 5 Å 内的口袋残基，3 条轨迹，每条 1 ns
python -m mdagent run --pdb examples/181L.pdb --around-ligand BNZ \
    --replicas 3 --ns 1 --out runs/181L

# 对已有的运行结果重新诊断
python -m mdagent diagnose --run runs/181L

pytest -q tests
```

速度参考：181L 体系约 3.5 万个原子，在 4 核 CPU 上约每天 3 ns。要观察侧链翻转，需要 GPU（`--platform CUDA`）。

## 测试体系

`examples/181L.pdb` 是 T4 溶菌酶 L99A 与苯的复合物。口袋里的 Val111 侧链在常规 MD 中很难翻转，这个现象已有文献报道。第一个里程碑是：agent 能自己把 Val111 标记为候选，并在增强采样之后给出两个状态的比例。

## 当前限制

- 配体会被去掉，只模拟蛋白本身。
- 质子化使用 PDBFixer 的默认规则，不预测蛋白内部的 pKa 变化。
- 平衡阶段没有对蛋白加位置约束。
- 只看 chi1，还没有看 chi2。

3. 做成异步的 agent 窗口：MD 在后台运行，定期汇报进度。
